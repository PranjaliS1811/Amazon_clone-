# Amazon Website Clone

## About the Project

This project is a front-end clone of Amazon's website, created to practice web development and improve my HTML and CSS skills.

## Technologies Used

* HTML5
* CSS3

## Features

* Amazon-inspired navigation bar
* Search bar design
* Product categories and sections
* Product display layout
* Footer section
